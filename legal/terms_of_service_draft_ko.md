## 제1장 총칙

### 제1조 (목적)

본 약관은 Uncounted(이하 "회사")가 제공하는 모바일 애플리케이션 및 웹 서비스(이하 "서비스")의 이용과 관련하여 회사와 이용자의 권리·의무 및 책임사항을 규정함을 목적으로 합니다.

### 제2조 (정의)

본 약관에서 사용하는 용어의 정의는 다음과 같습니다.

| 용어 | 정의 |
|---|---|
| **이용자** | 본 약관에 동의하고 회사가 제공하는 서비스를 이용하는 회원 |
| **회원** | 회사에 개인정보를 제공하여 회원등록을 한 자로서, 서비스를 지속적으로 이용할 수 있는 자 |
| **서비스** | 통화 음성 데이터의 비식별 처리 및 AI 학습용 데이터 거래 중개 서비스 |
| **음성 데이터** | 이용자가 보유한 통화 녹음 파일을 화자분리·PII 마스킹 처리한 결과물 |
| **메타데이터** | 음성 데이터에 부수하여 생성되는 통화 시각·시간·품질 메트릭·화자 인구통계 정보 |
| **양자 동의** | 통화 당사자(이용자)와 통화 상대방 모두의 동의를 받은 상태 |
| **본인 발화** | 이용자 본인의 음성 구간만 분리한 데이터 (`user_only`) |
| **양측 발화** | 양자 동의 완료 후 이용자와 상대방 음성 모두 포함된 데이터 (`both_agreed`) |
| **통화 (Call)** | 시간·기간·발화자 식별값으로 정규화된 단일 이벤트 단위 (call_id 기준). 동일 통화에 양측이 각각 업로드해도 시스템이 하나의 통화로 식별합니다. |
| **권리자 (Participant)** | 1통화의 발화자로서 보상 청구권을 가지는 자연인. 통화의 양측 모두가 권리자가 되며, 이용자 가입 여부와 무관하게 권리가 보존됩니다 (제11조 4항). |
| **프리미엄 통화 (PREMIUM)** | 양측 발화자가 모두 개인(이동전화·일반 유선)인 통화. 보상은 양측 권리자에게 50:50으로 분배됩니다. |
| **스탠다드 통화 (STANDARD)** | 한쪽 발화자가 기업 대표번호(1588 등) 또는 가상번호(050 등)인 통화. 직무 발화자 측은 권리자로 보지 아니하며, 거래 시 추가 비식별 처리(목소리 변형·실명 마스킹 강화)가 적용되고 보상은 개인 측 권리자에게 100% 분배됩니다. |
| **거래 불가 통화 (EXCLUDED)** | 양측 모두 비개인이거나 발화자 식별이 불가능한 통화. 거래 대상에서 제외되며 회사는 본 데이터를 매수자에게 제공하지 않습니다. |
| **데이터 패키지 (SKU)** | 회사가 제3자에게 제공하는 비식별 음성·메타데이터의 표준 단위. **UC-A1**(시드 6h 파일럿) / **UC-A2**(60h 트라이얼) / **UC-A3**(600h 정기 / 6,000h 대량) / **UC-LLM**(Instruction Data) 4단계로 구성됨. |
| **데이터 버전 (v)** | 600h 단위로 자동 분리되는 코호트 단위 데이터셋. 선가입자 우선 진입 + 중첩 없음 + 동질성 샘플링 원칙 적용. v1, v2, v3 ... 순번으로 발급. |
| **신선도 차등** | 데이터 버전의 발급 시점에 따른 단가 차등. 최신 vN(프리미엄) > vN-1 > vN-3 이전(할인). |
| **순이익** | 데이터 거래 매출에서 회사가 정의한 운영비(제18조)를 차감한 금액. 회사 유보 50% + 화자 보상 풀 50%로 분배. |
| **연간 보상 Cap** | 이용자 1인이 1역년(1월 1일~12월 31일)에 수령할 수 있는 보상금 상한. 본 약관 v1.1 시행일 기준 **₩3,000,000** (한국 「소득세법」상 기타소득 분리과세 한도 정합). 매년 1월 1일 자동 리셋. |
| **잉여 데이터** | 이용자의 보상이 Cap에 도달하여 당해 년도에 보상되지 못한 데이터. 다음 v로 자동 이월되어 영구 자산화. |
| **선가입자 우선** | v 진입 순서를 가입 시점 (signup_at) 기준으로 정렬하는 분배 원칙. 시간 가치 누적 모델. |

### 제3조 (약관의 효력 및 변경)

1. 본 약관은 회사가 서비스 화면에 게시하거나 기타의 방법으로 이용자에게 공지함으로써 효력이 발생합니다.
2. 회사는 「약관의 규제에 관한 법률」, 「정보통신망법」 등 관련 법령을 위배하지 않는 범위에서 본 약관을 변경할 수 있습니다.
3. 회사가 약관을 변경하는 경우에는 적용일자 및 변경 사유를 명시하여 시행 7일 전(이용자에게 불리한 변경의 경우 30일 전)부터 서비스 화면에 공지합니다.
4. 이용자가 변경된 약관에 동의하지 않는 경우 회원 탈퇴를 요청할 수 있으며, 변경된 약관의 효력 발생일 이후에도 서비스를 계속 이용하는 경우 약관 변경에 동의한 것으로 간주합니다.

## 제2장 서비스 이용 계약

### 제4조 (이용 계약의 성립)

1. 이용 계약은 이용자가 본 약관, 개인정보처리방침 및 별도의 동의 항목에 동의한 후 회원가입을 완료함으로써 성립합니다.
2. 회원가입 시 이용자는 다음 사항에 대해 별도로 동의해야 합니다.
   - 본 약관 (필수)
   - 개인정보처리방침 (필수)
   - 음성 데이터(생체정보 가능성 포함)의 수집·이용 (필수)
   - 비식별 처리된 데이터의 제3자 제공 (선택 — 미동의 시 보상금 지급 대상 아님)
   - 마케팅 정보 수신 (선택)

### 제5조 (회원가입 자격 및 거부)

1. 회원가입은 만 14세 이상의 자연인에 한합니다.
2. 회사는 다음 각 호에 해당하는 신청에 대하여 가입을 거부하거나 사후 회원자격을 박탈할 수 있습니다.
   - 타인의 명의를 도용하여 신청한 경우
   - 허위 정보를 기재한 경우
   - 사회의 안녕 및 질서, 미풍양속을 저해할 목적으로 신청한 경우
   - 본인의 통화가 아닌 제3자의 통화 녹음을 무단으로 업로드한 경우

### 제5조의2 (통화 상대방의 동의)

1. **동의 단위.** 회사는 통화 단위(제2조 "통화")로 상대방의 동의를 수집합니다. 한 번 받은 동의는 동일한 이용자와 동일한 상대방 사이의 모든 통화(과거 및 향후)에 적용되며, 매 통화마다 다시 받지 않습니다.

2. **등급별 동의 요건.**
   - **프리미엄 통화**: 양측 발화자 모두가 통화의 데이터 거래에 동의해야 합니다. 한쪽이 동의하지 않은 통화는 본인 발화 구간만 거래 대상으로 합니다.
   - **스탠다드 통화**: 직무 발화자 측은 사전 동의 대상에서 제외하되, 거래 시 추가 비식별 처리를 적용하여 식별 가능성을 차단합니다. 개인 측 권리자의 동의만으로 거래가 가능합니다.
   - **거래 불가 통화**: 어떠한 동의로도 거래되지 않습니다.

3. **STANDARD 비식별화 의무.** 회사는 스탠다드 통화의 매수자 인도 시 다음을 의무로 합니다.
   - 발화자 음색 변형 또는 음높이 조정
   - 실명·소속·직책 등 식별 가능 단어의 강화 마스킹
   - 통화 시각의 시·분 단위 일반화 (필요 시)

4. **권리 주장 시 거래 중단.** 직무 발화자(예: 콜센터 상담원, 의사, 변호사) 또는 그 사용자(고용주)가 회사에 본인을 직무 발화자로 식별하고 권리를 주장한 경우, 회사는 해당 통화의 추가 거래를 즉시 중단합니다. 이미 인도된 데이터는 제12조에 따릅니다.

5. **동의 시점의 약관 버전 박힘.** 상대방이 동의할 때 본 약관의 버전(예: v1.2), IP 주소, User-Agent, 동의 시각이 함께 기록됩니다. 본 정보는 분쟁 발생 시 회사·상대방의 합의 증빙으로만 사용됩니다.

### 제6조 (회원 탈퇴 및 자격 상실)

1. 이용자는 언제든지 앱 내 [설정 > 회원 탈퇴] 메뉴를 통해 탈퇴할 수 있습니다.
2. 탈퇴 시 회사는 「개인정보 보호법」 및 회사의 개인정보처리방침에 따라 이용자의 개인정보를 처리합니다.
3. **이미 제3자에게 제공된 데이터에 대해서는 회사가 직접 회수할 수 없으며, 이용자가 해당 제3자에게 직접 삭제를 요청해야 합니다.** 회사는 탈퇴 시점까지 제공된 제3자 목록을 이용자에게 안내합니다.
4. 탈퇴 시점 기준 **잉여 데이터** (제2조 정의)의 처리는 다음과 같습니다.
   - 미판매 잉여 데이터: 이용자 요청 시 영구 삭제
   - 판매 완료 잉여 데이터: 본조 3항 적용

## 제3장 서비스 이용

### 제7조 (서비스의 내용)

회사가 제공하는 서비스는 다음과 같습니다.

1. **음성 데이터 비식별 처리**: 이용자가 업로드한 통화 녹음 파일을 화자분리, 음성-텍스트 변환(STT), 개인식별정보(PII) 자동 마스킹 처리
2. **데이터 거래 중개**: 비식별 처리된 음성·메타데이터를 AI 모델 개발 기업·연구기관(이하 "구매자")에 제공
3. **보상금 정산·지급**: 구매자로부터 받은 대가 중 운영비를 차감한 순이익의 50%를 이용자에게 분배 (제11조)

### 제8조 (서비스 이용 시간)

서비스는 연중무휴 24시간 제공함을 원칙으로 하나, 시스템 점검·업데이트, 천재지변 등 불가피한 사유가 있는 경우 일시 중단될 수 있습니다.

### 제8조의2 (동의 철회)

1. **철회권의 보장.** 이용자(가입자) 및 통화 상대방은 자신의 동의를 언제든지 철회할 수 있습니다. 회사는 철회 요청을 받은 즉시 해당 권리자의 후속 거래를 차단합니다.

2. **판매 전 철회.** 철회 시점에 매수자에게 인도되지 않은 통화는 거래 풀에서 즉시 회수되어 추가로 거래되지 않습니다.

3. **판매 후 회수 불가.** 철회 시점 이전에 이미 매수자에게 인도된 통화는 본 약관 제12조에 따라 회사가 직접 회수할 수 없습니다. 회사는 철회 시점까지의 매수자 목록을 권리자에게 안내하며, 권리자가 해당 매수자에게 직접 삭제를 요청해야 합니다.

4. **재요청 쿨다운.** 동의 거절 또는 철회 후 90일 이내에는 회사가 동일 권리자에게 동의를 재요청하지 않습니다(스팸 방지). 이용자가 자발적으로 재초대를 보내는 것은 본 한도와 무관합니다.

5. **철회 사실의 확인 통지.** 회사는 철회 처리 완료 시 권리자가 제공한 연락 수단으로 처리 결과를 통지합니다.

### 제9조 (이용자의 의무)

이용자는 다음 행위를 하여서는 안 됩니다.

1. 본인의 통화가 아닌 타인 간의 통화 녹음을 업로드하는 행위 (「통신비밀보호법」 위반)
2. 동의하지 않은 통화 상대방의 음성을 본인 발화 구간을 넘어 제공하는 행위
3. 회사 또는 제3자의 권리를 침해하는 행위
4. 서비스의 정상적 운영을 방해하는 행위
5. 허위 정보 등록을 통해 보상금을 부정 수령하는 행위

## 제4장 데이터 거래 및 보상

### 제10조 (데이터 거래 조건)

1. 회사는 이용자의 비식별 처리된 데이터를 다음 조건으로 구매자에게 제공합니다.
   - **비독점 N회 판매**: 회사는 동일 데이터 버전(v)을 다수 구매자에게 동시에 제공할 수 있으며, v당 N회 판매 횟수는 시장 표준을 고려하여 5~10회를 상한으로 합니다.
   - **양자 동의 기반**: 통화 상대방의 음성이 포함된 데이터는 상대방 동의 완료(`both_agreed`) 시에만 제공합니다. 상대방 동의 미수신 시에는 본인 발화 구간(`user_only`)만 제공합니다.
   - **600h 단위 자동 분리**: 양자 동의 데이터가 600h 누적되면 자동으로 새로운 데이터 버전(v) 발급. 코호트 간 중첩 없음 + 가족/친구/업무 분포 동질성 샘플링.
   - **신선도 차등 단가**: 최신 v(프리미엄) > 직전 v > 3분기 이상 경과 v(할인). 구체적 단가는 시장 협상에 따라 변동 가능.

2. 데이터 패키지(SKU) 단계별 표준 단위:
   - **UC-A1 (시드)**: 6h 파일럿. 무료 검증 미끼. 가입자 20~100명 단계.
   - **UC-A2 (성장)**: 60h 트라이얼 / 600h 정기. 가입자 100~10,000명 / 10,000~100,000명 단계.
   - **UC-A3 (규모)**: 6,000h 대량. 가입자 100,000명+ 단계.
   - **UC-LLM (4세대)**: Instruction Tuning Data. 자동 분류·요약·QA 가공. 가입자 1,000,000명+ 단계.

3. 단가 정책: BM v10.0 정식 단가는 시장 검증(LOI 확보) 후 별도 공지. 회사는 단가 결정 과정의 투명성을 위해 분기별 매출·운영비·순이익 결산을 공개합니다(제13조 6항).

### 제11조 (보상금 지급)

1. **분배 모델 — 통화 등급별 차등** (v1.2)
   - **프리미엄 통화**: 양측 권리자에게 50:50으로 분배 (`revenue_share_basis = 'standard'`)
   - **스탠다드 통화**: 개인 측 권리자에게 100% 분배 (`revenue_share_basis = 'sole'`). 직무 발화자 측은 권리자가 아닙니다.
   - **거래 불가 통화**: 거래 자체가 발생하지 않으므로 분배 없음
   - 통화 단위 분배 후 잔여는 제18조 운영비를 차감한 순이익을 기준으로 회사 유보 50%와 화자 보상 풀 50%로 회계 처리합니다.

2. **화자 풀 분배 — 선가입자 우선 + 시간 비례**
   - 분배 단위: 데이터 버전(v) 1개 매출
   - 정렬 기준: `priority_index` (가입 시점 signup_at 기준 1=가장 먼저)
   - 시간 비례: `(매출 × 50%) / v 총 시간` × 본인 기여 시간

3. **Payout Hold — 다음달 15일 release** (v1.2)
   - 통화가 매수자에게 판매된 시각(`sold_at`) 기준 **다음달 15일 0시**에 보상금이 출금 가능 잔액(`available`)으로 전환됩니다.
   - 회사는 hold 기간 동안 매수자 분쟁·결함 발견·정산 정정 사유에 대비하여 자금을 유보합니다.
   - 매수자 LOI(Letter of Intent) 1건 확보 후 정책 재검토 — 시장 표준(예: 30일)과 비교하여 한도 조정 가능.

4. **미가입자 권리분 보관** (v1.2)
   - 통화 상대방이 가입 전인 권리자의 보상분은 회사가 별도 풀에 **5년간** 보관합니다.
   - 권리자가 본인 휴대전화 번호로 가입하거나 이전 번호를 등록(본조 5항)하면 자동으로 매칭되어 본인의 출금 가능 잔액에 합산됩니다.
   - 5년 경과 후 미수령 보상분은 「상법」상 채권 시효 만료로 회사 유보로 전환됩니다.

5. **이전 번호 등록 — 최대 3개** (v1.2)
   - 이용자는 본인의 현재 휴대전화 번호 외에 이전에 사용했던 번호를 최대 **2개** 추가 등록할 수 있습니다(현재 1 + 이전 2 = 총 3개).
   - 본 등록은 미가입 시점에 발생한 본인 권리분의 회복을 위한 것이며, 회사는 추가 본인 확인을 요구할 수 있습니다.
   - 한도 초과 등록은 시스템이 자동으로 차단하며, 한도 확장이 필요한 경우 고객지원에 문의해야 합니다(KYC 강화 후 검토).

6. **연간 보상 Cap**
   - **₩3,000,000 / 1역년 / 1인** (한국 「소득세법」 제21조 기타소득 분리과세 한도 정합)
   - 분리과세 6% 처리 (회사가 원천징수 후 지급)
   - **매년 1월 1일 자동 리셋**

7. **잉여 데이터 자동 이월**
   - 본인 누적 보상이 Cap에 도달한 시점부터, 본인 데이터의 추가 분배는 정지
   - 미분배된 본인 데이터는 자동으로 다음 v로 이월 (영구 자산)
   - 다음 역년에 새 Cap 한도 내에서 분배 재개

8. **지급 시점 및 방식**
   - 매월 말일 마감 → 다음달 15일 자동 송금
   - 22% 원천징수 (분리과세 6% + 부가세 등 법정 항목)
   - 회사는 매년 1월 말까지 전년도 지급 내역을 이용자에게 안내

9. **세무 분류 명시**
   - **연 ₩300만 이하**: 「소득세법」 제21조 기타소득 분리과세 (이용자 별도 신고 의무 없음)
   - **연 ₩300만 초과**: Cap에 도달한 경우만 발생하므로 본 약관에서는 발생하지 않음
   - 단 이용자가 Cap을 의도적으로 초과 수령하기 위한 부정 행위(중복 가입 등)는 제9조 5항에 따라 자격 상실

10. **보상금 청구권 시효**: 「상법」에 따라 지급일로부터 5년 (단, 본조 4항의 미가입자 권리분 보관 기간이 적용되는 경우 보관 종료일로부터 기산).

### 제12조 (데이터 회수 불가의 원칙)

1. **인도 후 회수 불가 원칙.** 회사가 매수자에게 인도한 데이터는 회사가 직접 회수할 수 없습니다. 이는 데이터 매수자의 학습 자산 안정성 보장과 거래 시장의 신뢰 확보를 위한 거래 관행에 따른 것입니다.

2. **이용자 권리.** 이용자가 회원 탈퇴 또는 동의 철회를 한 경우, 회사는 다음을 이행합니다.
   - 회사 내 보유 데이터(미인도분) 즉시 삭제
   - 납품 대기 중인 데이터 제공 취소(거래 풀에서 제거)
   - 잉여 데이터(다음 v 이월 대기) 영구 삭제 옵션
   - 이미 인도된 데이터의 매수자 목록을 이용자에게 안내
   - 매수자 측 삭제는 이용자가 해당 매수자에게 직접 요청해야 하며, 회사는 매수자 연락 정보·표준 요청 양식을 제공합니다.

3. **결정적 결함 시 회사 부담.** (v1.2) 인도된 데이터에 다음과 같은 결정적 결함이 발견된 경우 회사는 매수자와의 계약에 따라 회수·교체 또는 환불 등의 조치를 하며, 이로 인한 비용은 회사가 부담합니다.
   - 비식별 처리 누락 또는 결함으로 인한 재식별 가능성 확인
   - 권리자의 동의 없이 인도된 통화의 발견 (예: 시스템 결함, 권리 주장 사후 발견)
   - 「개인정보 보호법」, 「통신비밀보호법」 위반 사실의 사후 확인
   - 본 항의 비용은 회사 유보 50%에서 처리하며 권리자의 보상금에 영향을 주지 않습니다.

4. **이미 매수자가 보유한 데이터의 권리자 권리.** 권리자는 「개인정보 보호법」에 따라 매수자에게 직접 본인의 개인정보 처리 정지·삭제를 요구할 수 있으며, 회사는 본 요구를 위한 매수자 정보·연락 수단·표준 요청서를 제공할 의무를 부담합니다.

## 제5장 회사의 의무 및 면책

### 제13조 (회사의 의무)

회사는 다음의 의무를 이행합니다.

1. 이용자에게 안정적인 서비스 제공
2. 이용자의 개인정보 보호 (개인정보처리방침에 따름)
3. **PII 마스킹 정확도 ≥97%** 유지를 위한 지속적 모델 개선
4. **「KISA 비식별 조치 가이드라인」 준수** 및 재식별 위험도 평가
5. **데이터 매칭 및 분배 알고리즘의 투명한 공개** (이용자 대시보드 + 해시 검증 페이지)
6. **분기별 운영비 결산 공개** — 매 분기 마감 후 30일 내 사용자 대시보드에 게시
7. **외부 회계 감사 의무** — 가입자 10,000명+ 시점부터 매년 외부 회계법인 감사 + 보고서 공개

### 제14조 (이용자에 대한 통지)

회사는 이용자에 대한 통지를 하는 경우 이용자가 등록한 이메일 주소 또는 앱 내 푸시 알림으로 할 수 있습니다. 불특정 다수 이용자에 대한 통지는 7일 이상 서비스 화면에 게시함으로써 개별 통지에 갈음할 수 있습니다.

본조에 따른 회사의 의무 통지 대상에 다음이 포함됩니다.

- 분기별 운영비 결산 공개 (제13조 6항)
- 외부 회계 감사 보고서 공개 (제13조 7항)
- 단가 정책 변경
- 보상 Cap 변경 (세법 개정 등)
- 분배 알고리즘 변경

### 제15조 (면책)

1. 회사는 천재지변, 전쟁, 기간통신사업자의 서비스 중지 등 불가항력으로 인한 손해에 대해 책임지지 않습니다.
2. 회사는 이용자가 본 약관 제9조의 의무를 위반하여 발생한 손해(예: 타인의 통화 녹음을 무단 업로드)에 대해 책임지지 않으며, 해당 이용자에게 구상권을 행사할 수 있습니다.
3. 회사는 구매자가 제공받은 데이터를 약정된 목적 외로 사용한 경우, 회사가 구매자와 체결한 계약에 따라 조치를 취하되, 직접적인 데이터 회수 의무는 없습니다.
4. **시장 검증 단계 면책**: BM v10.0 단가 그리드는 시장 검증(LOI 1건 확보) 후 정식 채택됩니다. 시드 단계(가입자 100명 미만)에서 발생한 매출은 시장 검증 자료로 활용되며, 이 시기 보상금은 본 약관 제11조에 따라 산정되되 시장 단가 변동에 따라 추후 보정될 수 있습니다.

## 제6장 분쟁 해결

### 제16조 (관할 법원)

본 약관에 명시되지 않은 사항은 「전자상거래법」, 「약관의 규제에 관한 법률」, 회사가 정한 운영정책 및 관련 법령에 따릅니다.

본 약관 또는 서비스 이용과 관련하여 회사와 이용자 간에 분쟁이 발생한 경우, 양 당사자는 분쟁의 해결을 위해 성실히 협의하며, 협의가 이루어지지 않을 경우 「민사소송법」에 따른 관할 법원에 제소할 수 있습니다.

### 제17조 (준거법)

본 약관 및 서비스 이용에 관해서는 대한민국 법령을 적용합니다.

## 제7장 운영비 정의 (BM v10.0 신뢰 보강 — 신설)

### 제18조 (운영비의 정의 및 한도)

본 약관 제11조 1항의 "운영비"는 다음의 통상 사업비만을 의미하며, 비통상 비용은 회사 유보 50%에서 별도 처리합니다.

1. **포함 항목**
   - **인건비**: 정규 직원 급여, 4대 보험, 퇴직급여 충당. 경영진 보수는 본조 2항 한도 내.
   - **인프라**: GPU 서버, 클라우드 호스팅, 데이터베이스, CDN, 외부 API 사용료, 학습 데이터 다운로드(AI Hub 등)
   - **법무**: 법무 자문, 약관 작성, KISA·세무·노무 자문
   - **마케팅**: 가입자 모집, 광고, 콘텐츠 제작
   - **화자 모집**: 가입 사례비(₩2만/인 등), 추천 인센티브
   - **회계 감사**: 외부 회계법인 비용 (제13조 7항)

2. **경영진 보수 한도**
   - 시장 표준 범위 (₩45,000,000 ~ ₩200,000,000 / 인 / 연)
   - 한도 초과 시 회사 유보 50%에서 별도 처리 (운영비 미인정)

3. **비통상 비용 (운영비 제외)**
   - 경영진 보너스
   - 일회성 투자 (M&A, 부동산 취득 등)
   - 위험 비용 (소송 합의금, 벌금 등)
   - 위 항목은 회사 유보 50%에서 처리하며 화자 보상 풀에 영향 없음

4. **운영비 결산 공개 의무**
   - 분기별 마감 후 30일 내 사용자 대시보드에 항목별 결산 게시
   - 가입자 10,000명+ 시점부터 매년 외부 회계법인 감사 + 보고서 공개

5. **이용자의 이의제기권**
   - 이용자는 분기 결산에 대해 회사에 서면 이의를 제기할 수 있습니다.
   - 회사는 이의 접수일로부터 30일 내 답변 의무를 부담합니다.

## 제8장 중복 판매 방지 (개정, v1.3 — 비배타적 라이선스)

### 제19조 (비배타적 라이선스 + 매수자별 중복 판매 방지 원칙)

1. **고유 식별의 원칙.** 회사는 통화 단위로 고유 식별자(이하 "통화 식별자")를 발급하며, 동일 통화는 식별 알고리즘(시각·기간·발화자 정규화 해시)에 의해 양측이 각각 업로드해도 1건으로 통합 식별됩니다. 동일 통화의 양측 업로드는 별개의 판매로 처리되지 않습니다.

2. **비배타적 라이선스 (v1.3 개정).** 본 약관 제10조의 "비독점 N회 판매" 원칙에 따라, 동일 통화 데이터는 서로 다른 매수자에게 N회(시장 표준 5~10회) 판매될 수 있습니다. 다만 회사는 다음을 보장합니다.
   - **동일 매수자에 대한 중복 판매 차단.** 동일 매수자가 동일 통화를 두 번 이상 구매하지 못하도록 시스템 수준에서 차단합니다 (`UNIQUE(통화 식별자, 매수자 식별자)`).
   - **다른 매수자에 대한 추가 판매 허용.** 통화가 한 매수자에게 판매된 이후에도 다른 매수자에게 동일한 조건으로 판매할 수 있습니다.

3. **탈퇴 및 재가입 시 동일 적용.** 이용자가 탈퇴 후 재가입하거나 새로운 사용자 계정으로 동일 통화를 업로드하더라도, 통화 식별자 기준으로 이미 특정 매수자에게 판매된 데이터는 동일 매수자에게 다시 판매되지 않습니다. 본 차단은 권리자의 보상 청구권(제11조 4항)과는 별개이며, 권리자는 5년 보관 기간 내에 본인 권리분을 회수할 수 있습니다.

4. **모호 매칭의 처리.** 시스템이 두 통화를 동일 통화로 식별할지 여부에 모호성이 있는 경우(예: 인접 시각의 짧은 차이), 회사는 보수적으로 새로운 통화 식별자로 분리 등록하고 운영 검토 큐에 표시합니다. 검토 결과에 따라 사후 통합되거나 분리 유지될 수 있으며, 그 결과는 권리자 대시보드를 통해 안내됩니다.

5. **권리 주장 시 거래 보류.** 통화의 권리자 또는 그 대리인이 본인을 식별하고 거래 중단 또는 보상 청구를 한 경우, 회사는 해당 통화 식별자의 추가 거래를 즉시 보류하고 분쟁 처리 절차(향후 별도 정책)에 따라 해결합니다.

6. **개정 사유 (v1.3, 2026-05-05).** 본 조항은 v1.2의 "1 통화 = 1회 판매" 원칙을 비배타적 라이선스 모델로 개정한 결과입니다. v1.2 모델은 단일 매수자에게만 판매 가능하여 데이터 가치를 충분히 활용하지 못한다는 한계가 있었으며, v1.3은 매수자별 중복 방지를 유지하면서도 다양한 매수자에 대한 판매를 허용하여 화자 보상 가능성을 확대합니다. 단가 산정·분배 비율(50:50 + Cap ₩300만)·권리자 보호 기제는 v1.2와 동일합니다.

7. **발화 단위 다자 납품 (v1.3, 2026-05-10 신설).** BM v10 도입에 따라 통화는 회사 GPU 서버에서 발화(utterance) 단위로 분리·비식별 처리됩니다. 발화 단위 판매에 대해서도 본 조 2항의 원칙이 동일하게 적용됩니다.
   - 동일 발화는 서로 다른 매수자에게 N회(시장 표준 5~10회) 판매 가능합니다.
   - 동일 매수자가 동일 발화를 두 번 이상 구매하지 못하도록 시스템 수준에서 차단합니다 (`UNIQUE(발화 식별자, 매수자 식별자)`).
   - 통화 식별자 기준 차단(2항)과 발화 식별자 기준 차단(7항)은 중첩 적용됩니다.

## 제9장 데이터 처리 흐름 및 보관 기간 (BM v10, 신설)

### 제20조 (음성 데이터의 처리 흐름 및 보관 기간)

1. **처리 단계.** 회사는 이용자가 업로드한 통화 음성을 다음 단계로 처리합니다.

```
[1단계] 휴대폰 녹음 파일 업로드 (HTTPS 암호화 채널)
   ▼
[2단계] 회사 서버 raw 음성 저장소 (비공개 버킷)
   ▼  → 이 시점부터 30일 동안만 보관
[3단계] GPU 처리 서버 (STT + 화자분리 + PII 마스킹 + 품질 평가)
   ▼
[4단계] 비식별 처리된 발화(utterance) 단위 음성 + 텍스트
   ▼  → 이용자 동의 철회 시까지(최대 3년) 보관
[5단계] 검수 통과 후 제3자 제공 가능
   ▼
[6단계] raw 음성 자동 삭제 (업로드 후 30일 경과 시 비가역 삭제)
```

2. **raw 음성 30일 보관의 사유.** 회사는 raw 음성(원본 통화 녹음 파일)을 다음 목적에 한하여 30일 동안 단기 보관합니다.
   - GPU 처리 실패 시 재처리
   - 비식별 처리 결과의 품질 검증
   - 이용자의 사후 민원·이의제기 대응 (예: 잘못된 화자 분리 결과 정정 요청)
   - 회사의 처리 의무 이행을 증빙

3. **30일 경과 후 자동 삭제.** raw 음성은 업로드 시점으로부터 30일 경과 시 회사 시스템에서 비가역적으로 자동 삭제됩니다. 30일 경과 후에는 비식별 처리가 완료된 발화 세그먼트만 회사 서버에 잔존합니다.

4. **이용자의 사전 삭제 요청.** 이용자는 30일 경과 전에도 raw 음성의 즉시 삭제를 요청할 수 있습니다. 다만 그 시점에 해당 통화의 비식별 처리가 완료되지 않았다면 처리는 즉시 중단되며 발화 세그먼트는 생성되지 않습니다.

5. **개정 사유 (v1.3).** 본 조는 BM v10 도입에 따라 신설되었습니다. v1.2 까지 휴대폰 측에서 수행하던 STT·화자분리·PII 마스킹을 회사 GPU 서버로 이관하면서 raw 음성의 단기 서버 보관이 필수가 되었으며, 「개인정보 보호법」 제21조(개인정보의 파기) 및 시행령 제16조에 따라 보관 기간과 삭제 절차를 명시할 필요가 있어 본 조를 신설합니다. 30일 보관 기간은 처리 실패 재시도(통상 24~72시간) + 이용자 민원 대응 기간(통상 2주)을 포괄하는 최소 기간으로 산정되었습니다.
